# Contributing

Bug reports, feature requests, and design discussion are welcome through GitHub Issues.

External code, documentation, and other copyrighted contributions are currently paused.
Please do not submit patches or pull requests. The project intends to preserve the ability
to offer optional alternative license terms, which requires sufficient relicensing rights
from every contributor. No relicensing-capable contributor license agreement has yet been
approved, so maintainers cannot accept or merge external contributions.

This gate may reopen after an appropriate contributor license agreement is adopted. Until
then, discussion does not imply assignment or licensing of a contributor's work to the
project.
